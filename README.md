### 🧾 Generador de Códigos QR en Python
Este es un simple script en Python que genera un código QR a partir de una URL introducida por el usuario y lo guarda como imagen PNG en el escritorio.

---
### 🚀 Requisitos

- Python 3.x
- Módulo `qrcode`
- Módulo `Pillow` (usado por `qrcode`)
- OS compatible con `webbrowser` para abrir imágenes
---
### Instalación

```bash
pip install qrcode[pil]
```
---
### 📂 Estructura del Proyecto
- qr-generator/
- ├── main.py
- └── README.md
---
### ✅ Cómo usar
1. Ejecuta el script:
```bash
python main.py
```
2. Introduce una URL cuando se te pida.
3. El código QR se guardará en: (En este caso es a mi disco)
```bash
C:\Users\Shamuel\Desktop\QR\Mi_QR.png
```
4. El programa abrirá la imagen automáticamente.
